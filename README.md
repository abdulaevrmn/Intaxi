# İNTAXİ — Driver App

İNTAXİ sürücülər üçün Android tətbiqi.

## Texnologiyalar
- Kotlin
- Android Studio
- Jetpack Compose
- Material 3

## Package name
com.intaxi.driver

## Hazırkı mərhələ
- İlkin sürücü ekranı
- Onlayn / oflayn düyməsi
- Gündəlik gəlir göstəricisi
- Sifariş və kilometr bölməsi

## Növbəti mərhələlər
- GPS və xəritə
- Sürücü qeydiyyatı
- Server bağlantısı
- Real sifarişlərin qəbulu
- Sərnişin tətbiqi ilə əlaqə
